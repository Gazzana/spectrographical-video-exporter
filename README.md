# Spectographical Video Exporter

SVE is a sonogram creation software designed for electroacoustic music, inspired by [EAnalysis](https://github.com/pierrecouprie/eanalysis).

## Features

* Generation of spectogram and sonogram from audio file

## Dependencies
User must have these installed in order to use SVE
* [FFmpeg](https://ffmpeg.org/)
* [SoX](https://sourceforge.net/projects/sox/)
